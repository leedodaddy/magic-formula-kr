# 마법공식 순위 (코스피·코스닥)

조엘 그린블라트의 마법공식으로 코스피·코스닥 시가총액 상위 300개 종목의 순위를 매깁니다.

- **ROC (자본수익률)** = EBIT ÷ (순운전자본 + 유형자산)
- **이익수익률** = EBIT ÷ EV
- 두 순위를 더한 점수가 낮을수록 상위입니다. 금융, 유틸리티, 리츠, 투자지주회사는 순위에서 뺍니다.
